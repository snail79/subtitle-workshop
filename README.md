# 🎬 字幕工坊 (Subtitle Workshop)

> 单文件网页版字幕配音工具：载入视频 → 打字幕 → 三种方式生成配音 → 一键烧录导出成片。
> 无需安装、无需联网（配音可走本地引擎）、无需数据库——一个 HTML 文件就是一个完整应用。

## ✨ 功能一览

| 功能 | 说明 |
|---|---|
| 📂 视频载入 | 点击按钮或直接拖拽文件进页面；自动抓取首帧海报（黑场视频自动跳到 0.5s 处取画面） |
| 💬 字幕 | 插入 / 编辑 / 拖动即刻生效；5 套样式模板 + 字号 60%~160%；SRT 导入导出 |
| 🗣 TTS 配音 | 逐句合成、自动铺轨；推荐配合本地配音助手（离线合成，无需联网） |
| 🤖 AI 配音 | 11 种音色（含粤语 / 童声 / 英语 / 日语）；本地助手优先，失败自动降级微软在线语音 |
| 🎤 旁白录音 | 跟随画面口播，录音自动挂到开始时刻 |
| 📂 配音导入 | 导入外部音频文件；文件名以秒数开头自动定位（`6.9_开场.wav` → 6.9s） |
| 🎚 成片配音选择 | 导出前指定成片用哪一路配音：全部 / 仅TTS / 仅AI / 仅导入 / 仅录音 |
| 🎵 背景音乐 | 自动循环、音量可调、导出结尾自动淡出 |
| ⬇ 一键导出 | 字幕与配音实时烧录进视频，优先 MP4，不支持时自动改 WebM |
| 💾 自动保存 | 字幕文本与时间按视频文件名自动保存在本机，重开同一视频自动恢复 |
| 📖 内置帮助 | 使用说明弹窗 + 操作流程图，新手零门槛上手 |

## 🚀 快速开始

### 方式一：直接使用（最简单）

1. 下载本仓库的 `字幕工坊.html`
2. 双击用 Chrome / Edge 打开
3. 载入视频，跟着内置「❓ 使用说明」操作即可

### 方式二：启用本地配音助手（推荐，配音更快更稳）

1. 进入 `配音助手/` 目录
2. 双击 `启动配音服务.bat`（保持黑色小窗口开着）
3. 回到字幕工坊，TTS / AI 配音将自动走本地引擎（127.0.0.1:8765）

> 本地助手基于 Python + edge-tts，首次运行会自动安装依赖。

## 📁 目录结构

```

```

## 🧩 技术实现要点

- **单文件架构**：CSS / HTML / JS 全在一个文件里，无构建、无依赖、无后端
- **首帧海报**：`canvas.drawImage` 直画视频帧，绕开浏览器视频元素渲染差异；黑场片头自动抓 0.5s 帧
- **配音双通道**：本地 HTTP 助手（`/tts?text&voice&rate`，edge-tts 流式合成）优先 → 失败自动降级浏览器直连微软在线语音 → 全部失败时引导导入音频兜底
- **混音导出**：`AudioContext` 总线 + `MediaRecorder` 实时录制，字幕逐帧烧录到 canvas 再合成视频
- **本地持久化**：`localStorage` 按视频文件名自动保存字幕工程

## ⚠️ 已知限制

- 导出为实时录制：片长多久录多久，导出期间请保持页面在前台
- MP4 导出需要较新的 Chrome / Edge；旧浏览器自动回退 WebM
- 在线版（HTTPS 部署）无法访问本机 `127.0.0.1` 配音助手（浏览器混合内容限制），离线版无此问题
